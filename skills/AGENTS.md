# Reusable workflow sources

Own user workflows, triggers, declared effects, and directly supporting resources. Keep one source under each skill folder; preserve its offline/source/publication/verification contract. A review request never runs production. Do not add empty resources, session traces, or maintenance boilerplate to workflows. On folder/resource edits regenerate catalogs, run strict skill metadata validation, catalog check, whitespace check, and affected workflow checks. Promotion requires the repository CI-equivalent gate.

# Installation and validation traps

Editing a linked skill changes its installed source immediately; editing the repository does not refresh a copied installation. Inspect the installation type before diagnosing discovery drift.

Catalog files can be stale even when SKILL.md looks valid. Regenerate from front matter, then run the generator's check mode; do not repair only the generated description.

An optimizer can produce a syntactically valid but behaviorally weaker candidate. Compare safety gates, capabilities, references, and actual bundled resources before promotion. Passing metadata checks does not verify provider access or workflow outcomes.

The repository's `sleeping` source and personal ChatGPT copy are distinct. A successful local edit does not prove that the personal copy was updated; an unavailable editor is a concrete synchronization blocker.
